# Contributing to AI Build CI/CD Integration

First off, thank you for considering contributing to this AI-driven project! It's people like you that make the world of automated DevOps so exciting.

## 🧬 Code of Conduct
By participating in this project, you agree to abide by our standards of professional and respectful conduct.

## 🚀 How Can I Contribute?

### Reporting Bugs
- Use the **GitHub Issue Tracker**.
- Describe the environment (OS, Python version, LLM used).
- Provide a minimal reproducible example.

### Suggesting Enhancements
- Explain the logic behind the AI integration.
- Detail why this change would improve the CI/CD pipeline.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Ensure any new AI logic is documented in the `docs/` folder.
3. Update the `CHANGELOG.md` with your changes.
4. If you've added a new script, ensure it has associated unit tests.

## 🧪 Testing Guidelines
- All scripts must pass the AI-assisted smoke tests.
- Mock LLM responses where possible to save on API costs during CI.

## 🎨 Style Guide
- **Python**: Follow PEP 8.
- **Node.js**: Follow the AirBnB style guide.
- **Batch**: Keep scripts modular and use clear variable naming.
