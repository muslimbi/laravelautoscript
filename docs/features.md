# Application Feature Marketplace — LaravelAutoScript v2

LaravelAutoScript v2 includes a modular feature marketplace where application capabilities can be independently installed and configured.

## Available Features

| Feature ID | Name | Package / Artisan | Description |
|---|---|---|---|
| `permission` | Spatie RBAC | `spatie/laravel-permission` | Roles and permissions management |
| `activitylog` | Activity Log | `spatie/laravel-activitylog` | Audit logging for model changes |
| `media` | Media Library | `spatie/laravel-medialibrary` | File & image management |
| `api` | API / Sanctum | `laravel/sanctum` | API token authentication |
| `horizon` | Queue / Horizon | `laravel/horizon` | Queue dashboard for Redis |
| `reverb` | Realtime / Reverb | `laravel/reverb` | WebSockets broadcasting |
| `scout` | Search / Scout | `laravel/scout` | Full-text search engine |
| `notifications` | Notifications | Native | Laravel notification channels |
| `storage` | File Storage | `artisan storage:link` | Public disk symlink |
| `billing` | Billing / Cashier | `laravel/cashier` | Subscription and payment engine |
| `monitoring` | Pulse | `laravel/pulse` | Performance monitor |
| `scheduler` | Scheduler | Native | Cron schedule runner |
| `import-export` | Import/Export | `maatwebsite/excel` | Excel and CSV import/export |
| `flags` | Pennant | `laravel/pennant` | Feature flag management |
| `ai-sdk` | AI SDK | `laravel/ai` | AI foundation |
