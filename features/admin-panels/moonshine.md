# Feature: MoonShine Admin Panel

## Specification
- **Package**: `moonshine/moonshine`
- **Type**: Admin Panel
- **Description**: Open-source admin panel for Laravel applications built with Blade & Tailwind CSS.

## Installation Steps
```bash
composer require moonshine/moonshine
php artisan moonshine:install
```

## Validation
Check access at `http://localhost:8000/admin`.
