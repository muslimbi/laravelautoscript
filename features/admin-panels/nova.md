# Feature: Laravel Nova (Commercial)

## Specification
- **Package**: `laravel/nova`
- **Type**: Commercial Admin Panel
- **Description**: Beautifully designed administration panel for Laravel.

## Note on Licensing & Setup
Laravel Nova requires a paid license and access key.
To install Nova:
1. Configure your license credentials in `auth.json` or `composer.json` repositories.
2. Run `composer require laravel/nova`.
3. Run `php artisan nova:install`.
4. Run `php artisan migrate`.

LaravelAutoScript will never attempt to bypass commercial licensing and handles Nova configuration gracefully.
